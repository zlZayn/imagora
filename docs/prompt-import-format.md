# 提示词导入格式

> 用途：发给多模态模型时要求回复严格按此格式输出，「粘贴导入」按此格式整段解析、批量建卡。
> 数量不设上限——任意条数都能导入建卡；本格式与具体业务无关，通用。

## 固定输出格式

首先输出：

### 识别摘要

（简要列出从输入图片/素材中能确定的信息和无法确认的信息，供确认依据）

接着依次输出全部提示词，严格遵循如下格式（===和```text都算格式的一部分，ratio和正文在代码块内，标题在代码块外）：
=== 示例图1 ===
```text
ratio: 1:1
正向提示词：一段完整、自然、可直接复制到图生图模型的中文描述。
```
每条提示词内容完整，不可删减省略。

> 电商商品图专用模板（含固定图组顺序与批次命名）见 [ecom-prompt-import-format.md](ecom-prompt-import-format.md)。
