# 电商商品图提示词导入格式

> 用途：电商商品图场景专用模板——发给多模态模型时要求回复严格按此格式输出，「粘贴导入」按此格式整段解析、批量建卡。

## 固定输出格式

首先输出：

### 图片识别摘要

（简要列出产品类别、包装主色、包装风格、包装材质、真实可见文字和无法确认的信息）

接着依次输出全部提示词，严格遵循如下格式（===和```text都算格式的一部分，ratio和正文在代码块内，标题在代码块外）：
=== 轮播图1 ===
```text
ratio: 1:1
正向提示词：一段完整、自然、可直接复制到图生图模型的中文描述。
```
按顺序输出：轮播图1～轮播图5、详情图1～详情图5，每条提示词内容完整，不可删减省略。
