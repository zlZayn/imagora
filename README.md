# Imagora

AI 生图工作台：基于 OpenAI 兼容接口的生图工具，文生图 / 图生图一体，网店商品图、详情页图批量化生成，支持无限画布工作流编排。

## 它能做什么

- 网页界面一键生图：拖拽 / 粘贴 / 点击上传参考图（可多张，每张即时标注**文件名与大小**），输入提示词即出图
- 文生图与图生图自动切换：不传图 = 文生图，传图 = 图生图（可传多张参考图，用途由提示词决定）
- 多开页面并行生图：一个服务开多个窗口，自动编号互不冲突（见「多开页面」）
- 生成结果实时显示：每张图标注**分辨率、格式、文件大小与费用**，底部汇总**本次总费用与用时**
- 输出目录自由选择：手输路径或系统文件夹选择器，生成后一键"打开文件夹"定位
- 批量生图：按产品配置一次生成多张详情页图（任务预览表格 + 彩色进度条，预览模式不花钱）
- 命令行单张生图：适合脚本化调用

## 首次使用：设置 API Key（必做）

二选一，推荐方式 1：

**方式 1：.env 文件**（推荐）

```powershell
Copy-Item tools\.env.example tools\.env
# 编辑 tools\.env，填入：AIWANWU_API_KEY=sk-你的Key
```

**方式 2：环境变量**（仅当前终端生效）

```powershell
$env:AIWANWU_API_KEY = "sk-你的Key"
```

注意：`.env` 已 git 忽略，不会泄露；未设置 Key 时调用生图会明确报错，界面顶部也会显示黄色提示条。

## 快速开始

**一键启动（推荐）**：确保已安装 Python（含 `uv`）、Node.js，双击 `tools\启动生图工具.cmd` 即可。脚本自动完成：

- 检查前端构建状态——未构建或源码更新会询问是否现场构建（自动 `npm install` + `npm run build`），无需手动执行
- 探测端口——已有服务在跑则直接开窗、不重复启动；否则自动后台启动服务并等待就绪
- 开窗并进入彩色交互菜单（见「多开页面」）

以下命令在脚本覆盖范围之外时才需要（换端口、开发模式、批量、单张、测试）：

```powershell
cd tools
uv run python -m main ui --port 8080         # 换端口启动
cd tools/frontend; npm run dev               # 前端开发模式（热更新，需后端已启动）
uv run python -m main batch --config ..\薄荷脑皮肤抑菌乳膏\batch_prompts.json --dry-run   # 批量生图（预览不花钱，需先准备 batch_prompts.json）
uv run python -m main gen "a red apple on white background" -o out.png   # 单张生图
uv run pytest                                # 运行后端测试（零成本，不调 API）
uv run ruff check .                          # 后端 lint
cd tools/frontend; npm test; npm run lint    # 前端测试 + lint
```

> 批量配置 `batch_prompts.json` 需先在产品目录准备，格式见 `core/batch.py` 与 `ARCHITECTURE.md`。

## 多开页面（并行生图）

服务只需启动一次即可多窗口并行生图，互不冲突。推荐双击 `启动生图工具.cmd` 启动——脚本先检查前端构建状态，再探测端口是否已有服务在跑（已有则直接开窗、不重复启动），然后开窗并进入**彩色交互菜单**（rich 渲染）：

- 菜单实时显示服务状态：**服务地址 / 进程 PID / 已分配窗口编号**（netstat 探测 + `/api/status` 查询，无需手工记忆）
- 按 **N** → 自动开下一个编号窗口（服务端分配编号，绝不撞号）；按 **Q** → 停掉端口上的服务进程并退出——无论该服务由哪个脚本启动，都会一并停止，所有窗口随之失效（本次关闭即全部关闭）
- 也可手动指定 `http://127.0.0.1:7860/?win=5`

窗口行为：

- 窗口顶栏显示「窗口 #N」，每个窗口**主色按编号自动区分**（编号不同颜色不同、同编号刷新不变），多开一眼可辨
- 默认输出**优先记住的上次输出路径**（服务重启沿用），无记录时按窗口分区 `output/win{N}`
- 页面内「＋ 新窗口」按钮：**继承当前窗口的上传图片 / 尺寸 / 质量 / 输出路径**（图片在添加时已存入服务端，新窗口只传引用、秒开即见，不受浏览器存储上限影响），仅提示词不保留，方便多角度批量出图；命令行 `?win=` 打开则保持全新
- 同秒并发生成文件名不冲突；生成日志（`logs/generation.jsonl`）带窗口号，可按窗口溯源

## 画布工作流（无限画布）

顶部「经典表单 / 无限画布」tab 切换，也可直接打开 `http://127.0.0.1:7860/?mode=canvas`。画布适合多图多任务编排、图片复用与迭代精修。

- **元素**：图片节点（缩略图）+ 图片组节点（聚合多图）+ 提示词节点（提示词 / 尺寸 / 质量 / 输出路径 / 运行按钮）
- **连线即参考关系**：把图片连到提示词节点上 = 该图作为此任务的参考图；连线方向与类型硬约束（图片→提示词或图片组、图片组→提示词、提示词→图片结果），连错被拒绝。提示词节点顶部仅允许一条入边，多图请先连到「图片组」聚合后再连到提示词
- **图片可复用**：一张图可同时连多个提示词节点；同一文件画布上只出现一个节点（内容去重），复用走多条连线
- **节点操作栏**：悬停任意节点，右侧竖排浮出图标按钮（图片：预览 / 替换 / 删除；图片组：删除；提示词：状态灯 + 删除），悬停时节点整体置顶，不被相邻卡片遮挡
- **独立任务**：每个提示词节点是独立生成任务，点「运行」只带自己的入边图片；「全部运行」并行排队执行（并发 2）
- **运行状态灯**：提示词节点右侧操作栏顶部状态灯指示进度——就绪灰、排队琥珀、生成中品牌色呼吸、完成绿、失败红（秒数 / 张数 / 失败原因悬停看提示）；点「全部运行」后所有待运行节点立即置排队（按钮禁用），运行中每秒刷新计时，完成记录张数；单点「运行」时双层守卫（queuedRef / runningRef），同一节点不会重复触发
- **画布日志**：右下角浮层只露最新 5 条，新条目淡入上移，不挡画布操作；画布向下占满剩余空间
- **结果回流**：生成的结果图自动复制进画布成为新图片节点，可再连到别的提示词节点做迭代；回流前按 registryId 去重，避免画布上出现重复节点
- **核对不乱**：悬停/选中提示词节点会高亮它的所有入边与关联图片，一眼确认"这个任务带哪几张图"；运行日志明示参考图张数
- **自动整理**：工具栏「自动整理」按钮一键布局——全局三段式：参考图与图片组在上方、提示词横向排列在中间、生成结果在下方（各组以关联提示词为中心水平聚拢）；**先 Shift 框选再点则只整理选中的节点**（其余保持原位）；整理后自动 `fitView` 居中适应视图
- **保存 / 加载**：整个画布（节点 / 连线 / 参数 / 位置）可存为 JSON 工作流文件（默认 `output/workflows/`），随时加载还原；加载时缺失的图片节点会标红提示
- **画布图片**：统一存 `output/.canvas/`（永不自动清理，区别于 24h 清理的参考图缓存），注册表 `registry.json` 索引
- **入口操作**：工具栏上传图片（本地上传）、新建提示词卡片 / 新建图片组、生成历史导入（从历史记录批量进画布）；画布内 Shift+拖拽框选多节点后点「删除所选」、双击连线删除
- **键盘快捷键**：`Ctrl+Z` 撤销 / `Ctrl+Y` 恢复画布操作（与工具栏「撤销/恢复」一致）、`Delete` 删除选中节点（带退场动画）、`Ctrl+S` 保存工作流；输入框聚焦时快捷键不拦截，走浏览器原生行为
- **平滑动效**：新建/导入/回流节点淡入上移（多节点交错），删除节点淡出后再移除；连线统一流动，一眼看出图→词方向；新建卡片定位在当前视口中心，无需滚动寻找

- 生成需 30-120 秒，接口超时已放宽至 300 秒
- 提示词英文优先，减少歧义
