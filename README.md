# Imagora

译为想象集，一个 AI 生图工作台：基于 OpenAI 兼容接口的生图工具，文生图 / 图生图一体，网店商品图、详情页图批量化生成，支持无限画布工作流编排。

## 它能做什么

* 网页界面一键生图：拖拽 / 粘贴 / 点击上传参考图（可多张，每张即时标注**文件名与大小**）；不传图 = 文生图，传图 = 图生图，自动切换

* 多开页面并行生图：一个服务开多个窗口，自动编号互不冲突（见「多开页面」）

* 生成结果实时显示：每张图标注**分辨率、格式、文件大小与费用**，底部汇总**本次总费用与用时**

* 输出目录自由选择：手输路径或系统文件夹选择器，生成后一键「打开文件夹」定位

* 批量生图：按产品配置一次生成多张详情页图（任务预览表格 + 进度条，预览模式不花钱）

* 命令行单张生图：与网页表单完全对等，所有参数显式指定、参考图可多张、产物进历史与网页端一致（见「命令行（CLI）单张生成」）

* 提示词粘贴导入：把多模态模型按固定格式返回的整段提示词回复粘进画布，实时预览、批量建卡（格式见 [docs/prompt-import-format.md](docs/prompt-import-format.md)）

## 首次使用：设置 API Key（必做）

二选一，推荐方式 1：

**方式 1：.env 文件**（推荐）

```powershell
Copy-Item Imagora\.env.example Imagora\.env
# 编辑 Imagora\.env，填入：API_KEY_WANWU=sk-你的Key
```

**方式 2：环境变量**（仅当前终端生效）

```powershell
$env:API_KEY_WANWU = "sk-你的Key"
```

注意：`.env` 已 git 忽略，不会泄露；未设置 Key 时调用生图会明确报错，界面顶部显示黄色提示条。

## 切换中转站 / 多配置（profiles）

工具支持多套供应商配置并存、一行切换，不用改代码：

* **公开配置**（中转站地址 / 模型 / 尺寸 / 质量 / 比例）在 `config.json`（git 跟踪，团队共享默认）：`default_profile` 指定默认套，`profiles` 下可放多套（示例已含 `wanwu` 与 `other`——后者是占位示例，地址/模型需自行替换）。

* **密钥与本机覆盖**在 `.env`（git 忽略）：key 按 profile 命名 `API_KEY_<大写 profile 名>`，切换中转站时 key 自动跟随；旧写法 `AIWANWU_API_KEY` 仍兼容。

* **选择优先级**：环境变量 / `.env` 的 `ACTIVE_PROFILE` > `config.json` 的 `default_profile` > 内置默认。

三种场景：

1. **个人临时切站**：`.env` 加 `ACTIVE_PROFILE=other` + `API_KEY_OTHER=sk-...` 两行 → 重启，不污染公共配置
2. **团队换默认供应商**：改 `config.json` 的 `default_profile` 并提交 → 大家 pull 后生效
3. **新机器初始化**：`cp .env.example .env` → 填 Key → 其余默认即可用

切换后标题栏显示「当前 profile · 模型」徽章，一眼确认生效；配置写错（未知键 / 缺 profile / JSON 格式错）控制台警告并回退默认，不静默出错。

## 快速开始

**开发环境启动**：确保已安装 Python（含 `uv`）、Node.js，双击 `启动生图工作台.cmd` 即可。脚本自动完成：

* 检查前端构建状态——未构建或源码更新会询问是否现场构建（自动 `npm install` + `npm run build`）

* 探测端口——已有服务在跑则直接开窗，否则自动后台启动服务并等待就绪

* 开窗并进入彩色交互菜单（见「多开页面」）

脚本覆盖范围之外的手动命令（换端口、开发模式、批量、单张）：

```powershell
cd Imagora
uv run python -m main ui --port 8080         # 换端口启动
cd Imagora/frontend; npm run dev              # 前端开发模式（热更新，需后端已启动）
uv run python -m main batch --config ..\你的产品目录\batch_prompts.json --dry-run   # 批量（预览不花钱，先准备 batch_prompts.json）
uv run python -m main gen "a red apple" --size 1024x1024 --quality high -o out.png   # 单张生成
```

测试、lint、E2E 等开发命令见 [ARCHITECTURE.md](ARCHITECTURE.md) 第 10 章与 [AGENTS.md](AGENTS.md)「验证状态」。

## 命令行（CLI）单张生成

`gen` 子命令与网页表单完全对等，所有参数显式指定（缺必填项立即报错退出码 2，并提示运行 `config` 查看可用值）；成功后产物进历史账本，与网页端同源可互查。

**必填参数**：

* `prompt`（位置参数）：提示词，英文优先

* `--size` 或 `--ratio`（二选一）：分辨率字符串（如 `1024x1024`）或宽高比（如 `9:16`）

* `--quality`：`low` / `medium` / `high`（可用值见当前 profile）

* `--output` / `-o`：输出路径（文件路径直接用；目录则自动生成 `ai_<时间戳>_<序号>.<后缀>` 文件名）

**可选参数**：

* `-i` / `--image`：参考图路径，可多次传（传了即图生图）

* `--tier`：配合 `--ratio` 的档位（`1K`/`2K`/`4K`，默认 `2K`）

* `--model`：模型名（默认取当前 profile）

* `--n`：生成张数（默认 1）

* `--format`：输出格式 `png`/`jpg`/`webp`（默认 `png`；输出路径带后缀时以后缀为准）

* `--no-asset`：纯生成模式，跳过资产注册与历史记录

**`config` 子命令**：实时读取当前 profile 的 `config.json`，打印支持的尺寸（含费用）、比例 + 档位、质量取值、默认值，方便对照填参。

```powershell
uv run python -m main config
# 当前 profile: wanwu  ·  模型: gpt-image-2  ·  端点: https://2api.aiwanwu.cc
# 默认尺寸: 1024x1024  ·  默认质量: high  ·  默认档位: 2K
# 尺寸 SIZE_OPTIONS（--size 取 value）: 1024x1024 (1:1 1K) 费用 0.05 元 ...
# 比例 RATIOS（--ratio 取键，--tier 取档位）: 9:16 → 2K=1152x2048 / 4K=2160x3840 ...
# 质量 QUALITY_OPTIONS: low / medium / high
```

CLI 单次同步等待结果；需多张并行可开多个终端各跑一条 `gen` 命令。

## 多开页面（并行生图）

服务只需启动一次即可多窗口并行生图，互不冲突。双击启动脚本后进入**彩色交互菜单**：

* 菜单实时显示服务状态：服务地址 / 进程 PID / 已分配窗口编号（无需手工记忆）

* 按 **N** 开下一个编号窗口（服务端分配编号，绝不撞号）；按 **Q**（或关窗口 / Ctrl+C）**连根停掉端口上的全部服务进程**并退出——本次关闭即全部关闭

* 也可手动打开 `http://127.0.0.1:7860/?win=5`

窗口行为：

* 窗口顶栏显示「窗口 #N」，每个窗口**主色按编号自动区分**（浏览器标签页图标同色），多开一眼可辨

* 默认输出**优先记住的上次输出路径**（服务重启沿用），无记录时按窗口分区 `output/win{N}`

* 页面内「＋ 新窗口」按钮：**继承当前窗口的上传图片 / 尺寸 / 质量 / 输出路径**（仅提示词不保留），方便多角度批量出图；命令行 `?win=` 打开则保持全新

* 同秒并发生成文件名不冲突；生成日志带窗口号，可按窗口溯源

## 画布工作流（无限画布）

顶部「经典表单 / 无限画布」tab 切换，也可直接打开 `http://127.0.0.1:7860/?mode=canvas`。适合多图多任务编排、图片复用与迭代精修。

* **元素**：图片节点（缩略图）+ 图片组节点（聚合多图）+ 提示词节点（提示词 / 尺寸 / 质量 / 输出路径 / 运行按钮）；上传图片 / 新建卡片 / 图片组 / 历史导入都出现在当前视口中心

* **连线即参考关系**：图片连到提示词 = 该图作为此任务的参考图；连线类型硬约束（图片→提示词/图片组、图片组→提示词、提示词→图片结果），连错会被拒绝；提示词顶部仅一条入边，多图先连到「图片组」聚合

* **图片可复用**：一张图可同时连多个提示词节点；同一文件画布上只出现一个节点

* **独立任务**：每个提示词节点独立生成，「运行」只带自己的入边图片，「全部运行」提交到服务端并发队列（与经典表单同一管线）

* **运行状态灯**：排队琥珀、生成中品牌色呼吸（秒数显示在运行按钮上）、完成绿、失败红（悬停看原因，右下角日志有摘要）

* **结果回流 / 统一存储**：生成结果自动成为画布上的新图片节点，放在提示词卡片正下方，可继续连线迭代；**经典表单与画布同一套后端存储**，经典结果区可「导入画布」把该次生成（参考图→提示词→结果）整图还原

* **核对不乱**：悬停/选中提示词节点高亮它的所有入边与关联图片，一眼确认「这个任务带哪几张图」

* **自动整理**：按连线深度分层、提示词卡片自底向上层层定位；连续点击结果不变（不漂移），其余节点原位不动

* **保存 / 加载**：整个画布存为 JSON 工作流，随时还原；项目文件夹改名/移动后旧工作流依然可恢复

* **入口与操作**：拖拽本地图片（可多张）到画布松开即添加；新建卡片 / 图片组按钮可拖出到画布松开即建（点击仍自动居中）；工具栏上传 / 粘贴导入 / 生成历史导入；右键拖拽框选 / Ctrl+点击加选后出现操作栏（运行所选、自动整理、自动连线、设置输出路径、删除所选）；双击连线删除；画布内右键不弹浏览器菜单

* **键盘快捷键**：`Ctrl+A` 全选 · `Ctrl`+点击加选 · `Ctrl+Z` 撤销 / `Ctrl+Y` 恢复 · `Ctrl+S` 保存 · `Delete` 删除（输入框聚焦时不拦截）

* **缩放与预览**：滚轮缩放，左下角「适应视图」一键全览；双击图片打开预览弹窗（滚轮缩放、放大后拖拽平移、双击复位）；缩到很小视图节点切换为抽象卡片（只影响渲染，拖拽/选中/连线照常）

> 画布数据存储为版本化格式（v1/v2 自动兼容）；数据迁移 / 清单修复用独立脚本 `scripts/migrate.py`，属维护向操作，用法见 [ARCHITECTURE.md](ARCHITECTURE.md) 第 5.5 节，日常无需执行。

## 计费说明

计费与尺寸由 `config.json`（当前 profile 的 `size_options[].cost`）统一管理；界面尺寸下拉经 `/api/config` 实时下发，命令行 `gen --tier 4K` 按 profile 档位请求更高分辨率，费用按对应档位 `cost` 结算。

其他注意：

* 生成需 30-120 秒，接口超时已放宽至 300 秒

* 提示词英文优先，减少歧义
